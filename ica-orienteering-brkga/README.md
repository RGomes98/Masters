# Orienteering Problem with BRKGA

Project for the Applied Computational Intelligence course (2026-2).

The Orienteering Problem is a variant of the Traveling Salesman Problem. Given a time budget, the goal is to choose which places to visit, and in which order, to collect the largest total score. This project solves it with a Biased Random-Key Genetic Algorithm (BRKGA) written from scratch in Rust, tested on classic benchmark instances and on a one-day trip through the Sul Fluminense region of Rio de Janeiro state, starting and ending in Volta Redonda.
